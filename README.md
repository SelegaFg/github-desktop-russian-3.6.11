# 🇷🇺 GitHub Desktop — Русификатор для Windows

**Неофициальная русская локализация GitHub Desktop 3.6.11 для Windows 10/11.**

Русификатор позволяет пользоваться GitHub Desktop с частично переведённым на русский язык интерфейсом. Создан для пользователей, которым удобнее работать с репозиториями, ветками и коммитами на русском языке.

**Версия перевода:** 2.1.0 Preview  
**Совместимая версия GitHub Desktop:** 3.6.11 (x64)  
**Операционная система:** Windows 10 / Windows 11  
**Статус:** 🟡 Тестовая версия

---

## ✨ Возможности

- 🇷🇺 Более 1100 текстовых замен в интерфейсе.
- 📂 Перевод многих действий с репозиториями.
- 🌿 Перевод операций с ветками и коммитами.
- ⚙️ Перевод части настроек, меню и сообщений.
- 📦 Установка с помощью одного CMD-файла.
- 🔐 Проверка совместимости и SHA-256.
- 💾 Автоматическое резервное копирование оригинальных файлов.
- ↩️ Возможность вернуть английский интерфейс.
- 🚫 Для обычной установки не требуются Node.js, Git или Python.

> ⚠️ Перевод пока неполный. Некоторые окна, кнопки и сообщения могут оставаться на английском языке.

## 📥 Как скачать и установить

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте архив `GitHubDesktop-RU-3.6.11-v2.1-preview-Windows.zip`.
3. Распакуйте архив в отдельную папку.
4. Полностью закройте GitHub Desktop через **File → Exit**.
5. Запустите файл **`Установить.cmd`**.
6. Дождитесь сообщения об успешной установке.
7. Откройте GitHub Desktop.

После установки часть интерфейса станет русскоязычной.

**Не запускайте установщик непосредственно из ZIP-архива.**

Подробные инструкции: [INSTALL.md](INSTALL.md).

## ↩️ Как удалить русификатор

Чтобы восстановить английский язык:

1. Полностью закройте GitHub Desktop.
2. Откройте папку с русификатором.
3. Запустите **`Вернуть-английский.cmd`**.
4. Дождитесь завершения восстановления.
5. Перезапустите GitHub Desktop.

Резервные копии находятся по пути:

`%LOCALAPPDATA%\GitHubDesktop\RussianPatchBackups\3.6.11`

Не удаляйте эту папку, пока используете русификатор.

## 🔐 Как работает русификатор

При установке программа:

1. Проверяет поддерживаемую версию GitHub Desktop.
2. Сравнивает контрольные суммы исходных файлов.
3. Создаёт резервную копию оригиналов.
4. Применяет изменения перевода.
5. Проверяет полученные файлы.
6. Завершает установку или сообщает об ошибке.

Русификатор изменяет файлы установленного приложения, но не предназначен для изменения пользовательских репозиториев, учётных записей или проектов.

## 📌 Известные ограничения

- Перевод находится в разработке.
- Некоторые сообщения остаются английскими.
- После обновления GitHub Desktop может понадобиться новый патч.
- Другие сборки и модифицированные версии приложения не поддерживаются.
- Публичный установщик пока не прошёл полную проверку на Windows.
