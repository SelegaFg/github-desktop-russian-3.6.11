# Подробная инструкция для Windows

## 1. Проверка версии

1. Откройте GitHub Desktop.
2. В верхнем меню нажмите **Help → About GitHub Desktop**.
3. Убедитесь, что написано **Version 3.6.11 (x64)**.
4. Если версия другая, **не устанавливайте этот патч**.

## 2. Установка

1. Скачайте ZIP из раздела Releases проекта.
2. Правой кнопкой мыши → **Извлечь все**. Переносить отдельные файлы из архива нельзя — скрипты используют относительные пути.
3. Полностью закройте GitHub Desktop: **File → Exit**. Если приложение не закрывается, завершите его через Диспетчер задач.
4. Запустите `Установить.cmd` из распакованной папки; администратор обычно не нужен.
5. Дождитесь результата. При успешной установке будет `DONE: Russian localization 2.1 preview installed successfully.`
6. Нажмите любую клавишу и откройте GitHub Desktop.

Установщик не скачивает ничего из интернета, не обращается к вашим репозиториям и не запрашивает пароль GitHub. Он изменяет два файла программы только при полном совпадении SHA-256 с ожидаемыми значениями.

**Внимание:** Windows может предупредить о запуске незнакомого скрипта. Не отключайте антивирус и не обходите предупреждения, пока не проверите происхождение архива и содержимое `.ps1`.

## 3. Удаление русификации

1. Закройте GitHub Desktop.
2. Дважды нажмите `Вернуть-английский.cmd`.
3. Дождитесь `DONE: Original English files restored.`
4. Перезапустите программу.

Резервные копии английских файлов находятся в:

```text
%LOCALAPPDATA%\GitHubDesktop\RussianPatchBackups\3.6.11
```

Дополнительная копия состояния перед установкой хранится в подпапке `_before_public_install`.

## 4. Если возникла ошибка

| Сообщение / ситуация | Что делать |
| --- | --- |
| `Close GitHub Desktop` | Полностью закройте приложение и повторите запуск. |
| `GitHub Desktop 3.6.11 not found` | Проверьте версию и установку. Этот патч не поддерживает альтернативный путь или установку для всех пользователей. |
| `not a supported original/v1/v2 file` | Файлы отличаются от проверенного выпуска. **Не копируйте патч вручную.** |
| `original backup missing` | Для обновления поверх старого русификатора нужен исходный файл. Сначала восстановите оригиналы через старый установщик или переустановку точной версии. |
| `Delta SHA256 mismatch` | Архив распакован не полностью или изменён. Возьмите оригинальный ZIP релиза. |
| `Post-install SHA256 mismatch` | Ошибка записи. Проверьте восстановление из `_before_public_install` и резервные копии. |
| Смешение русского и английского | Известное ограничение тестового перевода, это не ошибка установки. |
| Программа не открывается | Закройте все процессы GitHub Desktop, запустите `Вернуть-английский.cmd`; при ошибке обратитесь в Issues. |

## 5. Работа с ранее установленными патчами

Установщик понимает только **точно известные SHA-256** исходной версии 3.6.11, патча v1 и патча v2. Для обновления с v1/v2 нужны оригинальные английские файлы в папке резервных копий. Если они отсутствуют, установщик остановится — это защитное поведение.

## 6. Вопросы и ответы

**Нужно ли удалять GitHub Desktop?** Нет, если версия и хеши совпадают.

**Изменятся ли мои Git-репозитории?** Скрипт работает только с `main.js`, `renderer.js` и резервными копиями. Однако перед экспериментами с ПО всегда полезно иметь резервные копии проектов.

**Нужен ли администратор?** Обычно нет для установки в `%LOCALAPPDATA%`. Если Windows отказывает в доступе, не повышайте права автоматически — сначала разберитесь с причиной.

**Почему не всё переведено?** Это предварительный выпуск, перечень переведённых элементов ограничен.

**Что произойдёт после обновления программы?** Обновлённые JS-файлы будут отличаться. Нужен новый совместимый патч.
