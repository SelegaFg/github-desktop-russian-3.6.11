# История изменений

## v2.1.0-preview — 11 ноября 2026

- Подготовлен комплект для публичного GitHub-репозитория.
- Полные файлы GitHub Desktop исключены из архива. Вместо них — компактные дельты, применяемые локально к строго проверенным оригиналам.
- Добавлены проверка SHA-256 для дельт, создание и проверка резервных копий, возможность отката и проверка результата до изменения файлов.
- Добавлены README, инструкции, правила сообщения об ошибках и публикации релиза.
- **Содержимое перевода то же, что в v2.0-preview:** 1116 замен. Новые языковые строки в v2.1 не добавлялись.

## v2.0-preview — 11 ноября 2026

- Исправлены многие непереведённые подписи стартового экрана.
- Дополнены строки для репозиториев, веток, коммитов, ошибок и настроек.
- Всего 1116 замен вместо 808 в v1.

## v1.0-preview — 11 ноября 2026

- Первый предварительный перевод части интерфейса GitHub Desktop 3.6.11.
