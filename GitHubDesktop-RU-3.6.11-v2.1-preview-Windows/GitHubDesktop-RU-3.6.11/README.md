# GitHub Desktop — русский интерфейс (3.6.11, Windows x64)

**Неофициальный русификатор GitHub Desktop для Windows 10/11.** Позволяет перевести часть интерфейса GitHub Desktop версии **3.6.11 (x64)** на русский язык. Установка выполняется локально, без сети, с проверкой контрольных сумм и созданием резервной копии английских файлов.

> ⚠️ **Тестовый выпуск `v2.1.0-preview`.** Перевод **не полный**. Некоторые окна, сообщения, подсказки и подписи остаются на английском. Запуск именно этого публичного пакета на Windows пока не проверен независимо. Используйте с пониманием риска и сохраните возможность отката.

## Совместимость

| Параметр | Поддерживается |
| --- | --- |
| GitHub Desktop | **3.6.11**, Windows x64, только проверенная сборка |
| ОС | Windows 10/11 (пользовательская установка в `%LOCALAPPDATA%`) |
| Предыдущий русификатор | Исходные файлы, известный патч v1 или v2 при наличии оригинальных резервных копий |
| Другие версии приложения | **Не поддерживаются** — скрипт откажется менять файлы |
| Нужны ли Node.js, Git или Python для установки? | **Нет** |

Чтобы узнать версию: **Help → About GitHub Desktop**.

## 📦 Установка

1. Загрузите ZIP-файл из **Releases** (лучше всего `GitHubDesktop-RU-3.6.11-v2.1-preview-Windows.zip`).
2. В Проводнике Windows нажмите по ZIP правой кнопкой → **Извлечь все**. **Не запускайте файл прямо из ZIP.**
3. Закройте GitHub Desktop через **File → Exit**.
4. Откройте распакованную папку и запустите **`Установить.cmd`** обычным двойным нажатием. Права администратора обычно не требуются.
5. Дождитесь строки `DONE: Russian localization 2.1 preview installed successfully.`
6. Откройте GitHub Desktop и проверьте перевод.

Если установщик вывел `ERROR`, **не повторяйте запуск вслепую**. Сделайте скриншот и прочитайте [инструкцию по ошибкам](INSTALL.md).

## ↩️ Как вернуть английский

1. Полностью закройте GitHub Desktop (**File → Exit**).
2. В той же папке запустите **`Вернуть-английский.cmd`**.
3. Дождитесь сообщения `DONE: Original English files restored.`
4. Перезапустите GitHub Desktop.

Оригиналы сохраняются в папку:

```text
%LOCALAPPDATA%\GitHubDesktop\RussianPatchBackups\3.6.11
```

Не удаляйте резервные копии, пока пользуетесь русификатором.

## Что переведено

- Меню, многие пункты настроек и действия с репозиториями.
- Часть стартового экрана, включая создание, клонирование и добавление репозитория.
- Многие надписи для веток, коммитов, конфликтов, публикации и синхронизации.

**Всего: 1116 замен в собранных JS-файлах** (62 для `main.js`, 1054 для `renderer.js`). Это количество замен, **не** процент полноты перевода. Фактический вид интерфейса зависит от раздела приложения.

## Как работает установка и почему это безопаснее полной замены файлов

Установщик сравнивает SHA-256 установленных `main.js` и `renderer.js` с известными оригинальными или ранее пропатченными файлами. Затем он берёт **локальные оригиналы**, применяет небольшие бинарные дельты (`patches/*.json`), проверяет SHA-256 результата **до записи** в приложение и сохраняет резервную копию. Если хеши не совпали, файлы не изменяются. При ошибке копирования предусмотрен откат к состоянию до установки; после сбоя проверьте его вручную.

Архив **не содержит полные файлы GitHub Desktop** и не содержит установщик самого GitHub Desktop. Не меняет пользовательские репозитории, но модифицирует установку приложения. Запуск сторонних скриптов всегда связан с риском: изучите `.ps1` перед запуском.

## Известные ограничения

- Перевод неполный. Некоторые строки на английском — ожидаемое поведение.
- После обновления GitHub Desktop патч может перестать работать. Не применяйте его к другой версии.
- При отличающейся сборке **3.6.11** проверка SHA-256 также может не пройти: это защита от порчи файлов.
- Если установлен иной мод или другой пакет приложения, установщик остановится.
- Публичная сборка подготовлена и сверена по исходным файлам, но полноценное пользовательское тестирование установки и всех окон ещё требуется.
